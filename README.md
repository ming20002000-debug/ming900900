# 아이돌 안무 월드컵 (여돌 vs 남돌)

여자 아이돌 안무(댄스 프랙티스) 영상 vs 남자 아이돌 안무 영상으로 진행되는 개인용 이상형 월드컵입니다.
순수 HTML/CSS/JS로만 만들어져 있어서 별도 설치 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 파일 구성

```
index.html   화면 구조
style.css    디자인
config.js    사이트 제목 / 선택 가능한 강수 설정
data.js      후보(곡) 데이터  ← 보통 이 파일만 수정하면 됩니다
script.js    토너먼트 진행 로직 (건드릴 필요 없음)
```

## 후보 데이터 수정하기 (`data.js`)

`data.js`를 열면 아래와 같은 형태의 배열이 있습니다.

```js
{ id: "f01", name: "(여자)아이들 ((G)I-DLE)", group: "", song: "퀸카 (Queencard)", gender: "female", youtubeId: "pKCaXYYwGjw", start: 0 },
```

| 필드 | 설명 |
|---|---|
| `id` | 다른 항목과 겹치지 않는 고유 값 |
| `name` | 화면에 표시될 이름 (그룹명) |
| `group` | 비고 (표시용, 비워둬도 됨) |
| `song` | 곡 제목 (표시용) |
| `gender` | `"female"`(여돌) 또는 `"male"`(남돌) — 이 값으로 구분합니다 |
| `youtubeId` | 유튜브 영상 주소의 `v=` (또는 `/shorts/`, `youtu.be/`) 뒤에 오는 11자리 코드 |
| `start` | 영상이 몇 초부터 재생될지 |

## 현재 들어있는 데이터

- 여돌 16팀 32곡 · 남돌 16팀 32곡 — 총 64개 안무 영상, 모든 그룹이 정확히 2곡씩입니다.
- 주신 링크를 그대로 채웠고, 각 영상은 유튜브 oEmbed(`title`/`author_name`)로 실제 그룹·곡과
  일치하는지 전부 확인했습니다. 확인 과정에서 발견된 사항:
  - 스트레이 키즈 항목에 섞여 있던 "WONDERLAND"·"BOUNCY" 링크는 실제로는 둘 다 ATEEZ 소속이었고,
    BOUNCY는 바로 아래 ATEEZ 항목과 중복이라 제외했습니다. 스트레이 키즈는 실제로 확인된
    "Back Door"·"특(S-Class)" 2곡만 들어있습니다.
  - 제로베이스원(ZB1) 두 번째 링크로 처음 주신 "Get A Guitar"는 oEmbed 확인 결과 RIIZE 공식
    채널 영상이라 제외했고, ZB1 두 번째 곡은 새로 주신 "ICONIK" 링크로 채웠습니다.
  - STAYC "ASAP"는 공식 채널이 아닌 미러(재업로드) 채널 영상입니다.
  - KiiiKiii "404 (New Era)"는 공식 KiiiKiii 채널이 아닌 'ARTBEAT' 채널 업로드 영상입니다.

## 설정 바꾸기 (`config.js`)

- `siteTitle`, `siteSubtitle` : 제목/부제목 문구
- `roundOptions` : 시작 화면에서 고를 수 있는 강수 목록 (기본 8/16/32/64)
- `defaultRound` : 시작 화면에 기본으로 선택되어 있는 강수

## 대결 매칭 방식

- 강수를 선택하면 후보 데이터 중 여돌/남돌 그룹에서 정확히 절반씩 무작위로 뽑아 대진을 만듭니다.
- 매 라운드마다 여돌 vs 남돌 매칭을 최대한 만들고, 인원이 안 맞을 경우에만 동성끼리 대결합니다. 홀수로 남으면 한 팀은 자동으로 다음 라운드에 진출합니다(부전승).
- 여돌 vs 남돌 매칭에서는 항상 화면 왼쪽 = 여돌, 오른쪽 = 남돌로 고정됩니다.

## GitHub Pages로 배포하기

1. 이 폴더 전체를 새 GitHub 저장소에 올립니다(push).
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Branch**를 배포할 브랜치(보통 `main`)와 루트 폴더(`/`)로 지정하고 저장합니다.
4. 잠시 후 `https://<계정이름>.github.io/<저장소이름>/` 주소로 접속하면 바로 사용할 수 있습니다.
